# Software Engineering

I build Python applications, explore algorithms, and document how software systems are designed, tested and delivered. This portfolio combines full applications, smaller code exercises and architecture diagrams.

## Applications

- [Planning Travel Costs](Applications/planning-travel-costs/) — I built a Python calculator for estimating travel, accommodation and rental costs.
- [Tracking Footwear Stock](Applications/tracking-footwear-stock/) — I built an inventory management program to track shoe records and stock levels.
- [Task Management Workflow](Applications/task-management-workflow/) — I built a command-line task manager that works with users, deadlines and task records.

## Algorithms

- [Music Library Search And Sorting](Algorithms/music-library-search-and-sorting/) — I explored sorting and searching algorithms using a collection of music album records.
- [Minesweeper Neighbourhood Analysis](Algorithms/minesweeper-neighbourhood-analysis/) — I implemented grid logic to identify mines around a cell in a Minesweeper-style board.

## Databases

- [Explore my database projects](Databases/) — I cover relational structures, SQL, SQLite and a bookstore inventory application.

## Architecture and Software Design

- [Modelling A Task Management System](Software-Architecture-and-Design/modelling-a-task-management-system/) — I used system design diagrams and MVC notes to model how a task-management system could work.

## More Technical Work

- [Programming Fundamentals](Programming-Fundamentals/) — Python, logic, data structures, exceptions, OOP and debugging.
- [Web Systems and Delivery](Web-Systems-and-Delivery/) — Web development, architecture, testing, Git and Docker.
