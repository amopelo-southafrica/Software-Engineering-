# Shoe Inventory Management

## What this project is about

I developed a Python inventory system to track shoes by code, product, cost and quantity. The script reads stock records and calculates inventory values.

## What I implemented

I used classes, file input/output, list operations and menu-driven workflows to manage product information.

## How to run

Provide an `inventory.txt` input file in the same directory, with header and rows formatted `Country,Code,Product,Cost,Quantity`, then run `python inventory.py`.

## Notes

The source reads a local `inventory.txt`; no company inventory dataset is published with the script. Stock-data validation and some messages require refinement.
