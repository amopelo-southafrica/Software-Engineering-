# Holiday Cost Planner

## What this project is about

I wrote a Python trip-budget calculator that combines flight prices, accommodation nights and car-rental days for supported South African destinations.

## What I implemented

I organized the calculations into functions and used conditional logic, user input and cost aggregation to produce trip estimates.

## How to run

`python holiday.py`

## Notes

The flight costs are example values, not current travel prices. Only the destinations and classes explicitly handled in the script are supported.
