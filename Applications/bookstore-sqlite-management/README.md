# Bookstore SQLite Management

## What this project is about

I built a command-line bookstore catalogue backed by an SQLite database. I designed workflows to add, update, remove, search and display books and author records.

## What I implemented

I used Python's `sqlite3` module, relational tables, SQL queries and a menu-driven interface to manage catalogue data.

## How to run

`python shelf_track.py`

## Notes

On first use, the script creates a local `ebookstore.db` file and seeds example books and authors. The menu is selected once per run.
