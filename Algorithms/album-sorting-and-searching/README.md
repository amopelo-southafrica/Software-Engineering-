# Album Sorting and Searching

## What this project is about

I modeled music albums as Python objects, wrote functions to sort album collections by different attributes and tested ways of searching the resulting records.

## What I implemented

I used Python classes, list manipulation, custom sort keys and a sequential-search routine. The implementation is in `album_management.py`.

## How to run

`python album_management.py`

## Notes

The original sequential-search routine returns too early, and the sample Album constructor arguments mix up artist and track count. Those sections need correction before treating search output as reliable.
