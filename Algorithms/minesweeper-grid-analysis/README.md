# Minesweeper Grid Neighbour Counts

## What this project is about

I wrote an algorithm that examines a two-dimensional Minesweeper grid and counts adjacent mines for each non-mine cell.

## What I implemented

I implemented the grid traversal with nested Python lists, loops, neighbour offsets and boundary checks. The code is in `minesweeper.py`.

## How to run

`python minesweeper.py` to print the sample grid with adjacent-mine counts.

## Notes

The script processes a predefined grid; it does not implement a full interactive game.
